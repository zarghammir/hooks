# Hooks

Hooks run by themselves, so there's nothing to remember in each window. These are for Claude Code.

★ = my picks.

| Hook | What it does |
|---|---|
| ★ [clean-desk](clean-desk/) | One sticky note per agent, read by itself on every restart. Old logs stay in the drawer until a job needs them. |
| [lean-lanes](lean-lanes/) | Six rules every agent starts with, so a team uses less without cutting corners: shorter sessions, fewer wake-up messages, cheaper models for plain reading. |
